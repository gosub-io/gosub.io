Current status of the project

Gosub is in its very early stages. Since Gosub is not a mere shell around an existing engine, it will take time before we can introduce a browser. Here is where each core component stands today.

25 m · the shallows

HTML parser

Working

Almost all HTML5 documents are parsed correctly, and the parser passes nearly all tests from the html5lib test suite. Current focus:

  • Optimizing performance and memory usage
  • Improving handling of invalid HTML
  • Reducing unnecessary memory copying
  • Separating parsing from the tree-building phase

Bytestream

Proof of concept

The first component in the pipeline: it reads input from the network and passes it on to the parsers. Current focus:

  • Automatic encoding detection
  • Minimizing data copying throughout the stream

CSS3 parser

Proof of concept

Already parses a large amount of real-world CSS correctly. It consists of:

  • The core CSS parser
  • A CSS value-syntax parser for validating property values

Render pipeline

Proof of concept

Still in its infancy, the pipeline is being designed from the ground up to handle DOM changes and re-render efficiently.

  • Efficient handling of DOM mutations
  • Incremental re-rendering

JavaScript engine

Early stage

An initial implementation built on V8, designed behind a pluggable interface so other engines can be swapped in later.

  • V8 integration through the pluggable engine API
  • Basic console API implementation

Engine foundations

In progress

Ongoing work on everything that ties the components together.

  • Networking stack
  • Configuration system
  • Modular engine architecture
